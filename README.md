# Android Quiz App 

This project is an Android quiz application developed in **Java** using **Android Studio** for **COSC 341 Lab 3 - Question 1**.

## Features

- Welcome screen with:
  - spinner to choose the number of questions (**1 to 4**)
  - spinner to choose a quiz category
  - **Load Quiz** button
- Three quiz categories:
  - Canadian Capitals
  - About Canada
  - Canadian Mountains
- Quiz screen with:
  - question number display
  - question text
  - related image
  - four multiple-choice options using radio buttons
  - **Next** / **Finish** button
- Result screen showing:
  - final score
  - **Done** button to return to the main screen

## Functionality

- The user must select both the number of questions and a category before starting.
- The app checks the selected answer for each question.
- The score is calculated and shown at the end of the quiz.
- On the last question, the **Next** button changes to **Finish**.
- Pressing **Done** returns the user to the welcome screen.

## Tools Used

- **Java**
- **Android Studio**
- **XML layouts**

## Purpose

This app was created to practice:
- multi-activity Android development
- passing data between activities using **Intent**
- working with **Spinner**, **RadioGroup**, **ImageView**, **ListView**, and **Button**
- basic quiz logic and user interaction in Android
